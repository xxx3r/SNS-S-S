# Researcher Brief: Sunday Evidence Loop

## Purpose

Translate external research into weighted belief updates, explicit uncertainty, and small repo quests.

## Required output

Each weekly roundup must include machine-usable front matter with:

- `weighted_belief_shifts`
- `suggested_actions`
- `sns_awareness_update`

Use `calendar/roundups/TEMPLATE.md`.

## Review sequence

1. Search the eight SNS research paths.
2. Prefer primary sources and real demonstrations.
3. Separate capability evidence from project relevance.
4. Record negative and contradictory evidence.
5. Assign confidence to each belief shift.
6. Convert only the strongest consequences into quests.
7. Keep 3–8 active quests total.
8. Update the monthly synthesis when the month closes.

## Translation questions

- Which model parameter should change?
- Which constraint became sharper?
- Which assumption should be retired?
- What experiment would distinguish competing interpretations?
- Does the finding improve hardware plausibility, surveying value, or merely narrative resonance?

## Safety against hype

Do not translate a laboratory record, press release, or speculative paper directly into mission readiness. State scale, environment, duration, and missing validation.
