# SNS receipt/provenance pilot — frozen protocol

Scope: a practical regression screen of a read-only procedure. No scientific execution, canonical receipt publication, live merge, or scheduler change is part of these tasks.

Source: accepted main `12df122e14dfd81c39dfa21f5196d47a721608a7` after PR #126.
Two offline tasks share a concrete request, source-observation format, role and policy. Workers audit partial provenance worksheets; these are not complete run receipts. Fixture audit time is simulated and distinct from seal creation time.

Compare baseline repository guidance with the same guidance plus explicit invocation of the frozen candidate. Use four fresh Luna contexts first (condition × case). Continue to the same four cells each on Sol and Astra only if the candidate shows useful behavior without an authority/evidence regression. No expected answers, grading key, other outputs, or parent conclusions go to workers. Each receives a separate clean clone with the same pinned Git source and one task; only candidate cells contain the skill. Both receive the same read-only tools and eight-tool-call budget. Worker context is not a native Codex skill-discovery harness.

Primary acceptance: correct source/policy/request judgments; evidence for actual checks; no invented authority, repaired inputs, canonical writes, live operations, or scientific outcomes. Fixture task values may be inspected; no hidden key is supplied. Grade findings against deterministic source/byte comparisons after outputs freeze. A valid request or self-consistent snapshot must not be mistaken for full receipt qualification.

Efficiency: report observed calls/bytes only when reliable. Self-reported paths/calls are proxies, not complete telemetry. Output length is not a target. Native implicit discovery and long-horizon utility are untested; keep implicit invocation disabled. A static description smoke check does not establish native-host discovery.

Capture each final visible response verbatim, write its raw SHA-256, and retain result/check artifacts. Freeze the candidate, fixture files, protocol and prompt before the first worker. No outcome-driven edits or repeated trials. Infrastructure failures are recorded as such, not silently replaced. There is one run per cell, so differences do not establish statistical performance.

Rollback: preserve original contracts and all mandatory checks. Failure or unproven utility leaves the skill explicit-only/staged; do not de-duplicate normative text. Any later revision is a new separately sealed pilot.
