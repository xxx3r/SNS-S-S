## 3. Detailed notes

### QST-STOR-0002

**Current artifact state**

- Geometry, thermal storage, package conductance, packaged-shadow survival, architectural escape, mission-shadow feasibility, matched mission dependency, and versioned allocation artifacts exist.
- The complete-package 10 mm / 30-minute screening branch has zero thermal survivors while all declared electrical cases pass.
- PR #37 fixed the configuration comparator's `KeyError`, added focused receipt-bearing evidence, resolved review, and merged with full repository validation explicitly marked not exposed.

**Blocker boundary**

The remaining problem is not missing paperwork. It is whether the architecture grows, constrains mission eclipse/target selection, or transfers thermal/storage responsibility to a host. Package-scale evidence and illuminated-state rejection remain real scientific gates.

**Stale state**

`memory/mem_log_short.md` and the active quest file still describe the matched dependency comparison as next work. That work is already accepted. Only monthly governance may rewrite the canonical memory and quest direction.

### QST-SIM-0002

The existing `AsteroidWorld` baseline is useful but does not yet test the quest's central claim about temporal/spatial advantage under realistic-enough rotation and stale coverage. A new experiment is required; no clerical action can establish that advantage.

### QST-SIM-0003

The GEO baseline must expose receivers, visibility, starvation, relay losses, and storage-role effects. Aggregate host energy alone would be insufficient. This is model and experiment design, not repository debris.

### QST-PV-0001

The quest explicitly requires test-condition-aware source translation. Because literature values may not transfer cleanly across radiation, temperature, recovery, and damage contexts, the absence of a single coefficient is not a schema failure. Scenario bands may be the correct scientific result.

### QST-META-0001

The abstraction must remain physically modest. It should bound data-link or reflection-control usefulness and falsify power relaying when pointing, conversion, and control losses dominate. Implementation and assumptions are the work.

### QST-ARCI-0001

The code scaffold is not yet a credible target assessment. Sensitivity and missing-data behavior determine whether ARCI can support a headline grade or must remain a multidimensional dashboard. Choosing ARCI as the next primary path requires governance because it competes with the current STOR default spawn.

### QST-CALENDAR-0001

This quest contains the only clearly separable active-quest cleanup slice:

- CLI generation into a staging directory;
- deterministic duplicate-ID validation;
- no automatic activation.

A real Sunday roundup, evidence interpretation, belief proposal, and queue consequence remain owned by the weekly and monthly loops.

### QST-FUND-0001

Mechanical validation can check links and reproduction commands. Writing the actual artifact, selecting claims, and synthesizing evidence are substantive. Existing website or concept materials should be treated as inputs only when they are explicitly imported and cited by the repository artifact.
